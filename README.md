# Persistence Dynamics of Regional Tourism Demand in Spain

Quarto conversion of the Word manuscript supplied in this repository. The original manuscript remains unchanged.

## Files

- `index.qmd`: paper text, abstract, mathematical expressions and seven tables.
- `_quarto.yml`: standalone paper-site configuration.
- `styles.css`: Zinkea colours and horizontally scrollable tables.
- `TEU-Revised final manuscript_RV2_limpio.docx`: original source.
- `CONVERSION_NOTES.md`: checks performed and source issues requiring author review.

## Preview

Install Quarto, open a terminal in this repository and run:

```powershell
quarto preview
```

## Render

```powershell
quarto render
```

The rendered site is written to `_site/`. Rendering does not publish or deploy the paper.
